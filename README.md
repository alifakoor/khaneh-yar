# خانه‌یار

وب‌اپ فارسی برای ثبت، امتیازدهی و مقایسه گزینه‌های خرید خانه. هر کاربر با شماره موبایل و کد یک‌بارمصرف (OTP از طریق sms.ir) ثبت‌نام/وارد می‌شود و فضای خصوصی خودش را دارد؛ داده‌ها در MongoDB ذخیره می‌شوند.

## اجرای توسعه

```bash
cp .env.example .env.local   # SMS_PROVIDER=console و MONGODB_URI محلی را تنظیم کنید
npm install
npm run dev
```

با `SMS_PROVIDER=console` کد ورود به‌جای پیامک در لاگ سرور چاپ می‌شود (در production مجاز نیست). کاربر جدید در اولین ورود، تنظیمات پیش‌فرض و دو ملک نمونه می‌گیرد.

## کنترل کیفیت

```bash
npm test          # تست‌های واحد + تست‌های API با MongoDB درون‌حافظه‌ای
npm run lint
npm run format:check
npm run build
```

اولین اجرای `npm test` باینری MongoDB را برای `mongodb-memory-server` دانلود می‌کند.

## استقرار روی دارکوب (همروش)

آدرس: `https://khaneh-yar.darkube.ir`. HTTPS و Ingress را دارکوب فراهم می‌کند و اپ از روی `Dockerfile` ساخته می‌شود (پورت `3000`).

### ۱. پیش‌نیازها

- یک سرویس MongoDB روی دارکوب بسازید و آدرس اتصالش را بردارید.
- در sms.ir قالب verify با شناسه `306964` باید پارامتر `CODE` داشته باشد (مثلاً: `کد ورود خانه‌یار: #CODE#`).

### ۲. متغیرهای محیطی اپ (در پنل دارکوب، به‌صورت Secret)

| متغیر               | مقدار                                                                             |
| ------------------- | --------------------------------------------------------------------------------- |
| `MONGODB_URI`       | آدرس اتصال MongoDB دارکوب                                                         |
| `MONGODB_DB`        | `khanehyar`                                                                       |
| `APP_ORIGIN`        | `https://khaneh-yar.darkube.ir`                                                   |
| `SESSION_SECRET`    | خروجی `openssl rand -hex 32` (تغییرش همه را خارج می‌کند)                          |
| `SMS_PROVIDER`      | `smsir`                                                                           |
| `SMSIR_API_KEY`     | کلید API پنل sms.ir                                                               |
| `SMSIR_TEMPLATE_ID` | `306964`                                                                          |
| `CLIENT_IP_HEADER`  | `x-real-ip` (پیش‌فرض؛ اگر Ingress فقط `x-forwarded-for` می‌فرستد همان را بگذارید) |

- Health check: مسیر `/api/health` روی پورت `3000` (وقتی به MongoDB وصل است ۲۰۰ برمی‌گرداند).

### ۳. مهاجرت حساب مدیر قبلی

فقط اگر داده‌ای از نسخه قبلی (ورود با نام‌کاربری/رمز) دارید، **پیش از اولین ورود با OTP** در ترمینال اپ روی دارکوب اجرا کنید:

```bash
ADMIN_PHONE=09xxxxxxxxx node scripts/migrate-admin-to-phone.mjs
```

خروجی `migrated` یعنی حساب قبلی با همه خانه‌ها و تنظیماتش به آن شماره منتقل شد؛ `no-legacy-user` یعنی داده قبلی‌ای نبود. اگر پیش از مهاجرت با همان شماره وارد شده باشید اسکریپت خطا می‌دهد؛ آن حساب تازه را از بخش تنظیمات حذف و دوباره اجرا کنید.

### ۴. بررسی بعد از استقرار

- ورود از موبایل با پیامک واقعی.
- محدودیت نرخ به IP واقعی کاربر وابسته است. اگر هدر IP به اپ نرسد، محدودیت IP نادیده گرفته می‌شود (محدودیت هر شماره همچنان فعال است)؛ ولی اگر Ingress برای همه یک IP (مثلاً IP لودبالانسر) بفرستد، همه کاربران در یک سهمیه ۲۰ پیامک در ساعت می‌افتند. پس از استقرار، ورود هم‌زمان از دو شبکه مختلف را امتحان کنید؛ در صورت مشکل `CLIENT_IP_HEADER` را عوض کنید.

### ۵. بکاپ

اگر دارکوب برای MongoDB بکاپ خودکار دارد، فعالش کنید. در غیر این صورت، از هر جایی که به دیتابیس دسترسی دارد:

```bash
MONGODB_URI='...' ./scripts/backup.sh
```

بکاپ‌ها ۱۴ روز در `backups/` نگه داشته می‌شوند؛ دستور بازگردانی در ابتدای `scripts/backup.sh` است.

### اجرای محلی کامل با Docker Compose

`docker-compose.yml` برای اجرای محلی یا سرور شخصی است (MongoDB با کاربر کم‌دسترسی که `deploy/mongo-init` می‌سازد، اپ فقط روی `127.0.0.1:3000`):

```bash
cp .env.example .env   # رمزها و کلید sms.ir را پر کنید
docker compose up -d --build
```

- محدودیت ساعتی: ۵ پیامک برای هر شماره، ۲۰ برای هر IP؛ ۱۰ تلاش تأیید برای هر شماره، ۵۰ برای هر IP.
